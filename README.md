# MAEH Showcase

Every night at 01:00 the previous day's results of eight demo trading accounts are
checked and **frozen** into a plain, browsable folder of files, accounts are ranked
with **Star crowns**, and a static dashboard shows every day.

> Demo accounts only. Nothing here is financial advice. See [DISCLAIMER.md](DISCLAIMER.md).
